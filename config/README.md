# Configuracao do modelo selecionado

Execute `python -m src.select_best_model` depois dos cinco treinamentos. O
comando criara `best_model.json` nesta pasta com o run ID e a URI do modelo que
sera carregado pela API.

O arquivo e especifico dos runs gerados em cada computador e, por isso, nao vem
preenchido no pacote do projeto.
